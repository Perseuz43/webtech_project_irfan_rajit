Max 1 MB and 1000 students per file. Either all students are imported or none, so a mistake never leaves half a class behind.

How to prepare the file

  1. Start from the sample: download students-sample.csv. It opens in Excel or Google Sheets.
  2. Keep the first row (the column names). Add one student per row.
  3. Save or export as CSV (in Excel: CSV UTF-8).
ColumnRequiredWhat to put there
nameYesFull name
rollYesA positive number, unique inside the class
classYesThe class name exactly as it appears under Classes
sectionNoA section of that class, for example A
guardianNoGuardian's name
phoneNoDigits, spaces, + and - only
usernameYes3-30 letters, numbers, dot, dash or underscore. Must be unique
passwordYesAt least 6 characters. Students can change it after logging in
